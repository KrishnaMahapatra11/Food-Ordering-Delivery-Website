
# Food Ordering and Delivery Website (MERN Stack)

## Project Overview

This project is a full-stack web application for a **Food Ordering and Delivery System** built using the **MERN stack** (MongoDB, Express.js, React, Node.js). The platform enables users to browse restaurants, view menus, manage their cart, place orders, and track their order history with a seamless, user-friendly interface.

## Features

- **User Authentication:**
  - Users can sign up, log in, and manage their profiles, including updating profile details and passwords.
  
- **Browse Restaurants:**
  - Displays a list of restaurants with ratings, addresses, and search/filtering options.
  
- **Menu Viewing:**
  - Shows restaurant menus with details, including dish prices, descriptions, and images.
  
- **Cart Management:**
  - Allows users to add/remove items from their cart, adjust quantities, and view the cart.
  
- **Order Placement:**
  - Users can place orders and specify delivery addresses.

- **Payment Integration:**
  - Secure payment processing through an integrated payment gateway.

- **Order History:**
  - Displays users' past orders along with the status of current orders.

- **Responsive Design:**
  - Ensures the website is fully responsive across various devices and screen sizes.

## Application Architecture

The app is structured as follows:

1. **Frontend (React):**
   - Pages include Home, Login/Signup, Menu, Cart, Order Confirmation, and Order History.
   - Features a clean and modern user interface.

2. **Backend (Node.js & Express):**
   - Handles user authentication, order processing, and communication with the database.
   
3. **Database (MongoDB):**
   - Stores user profiles, order history, and menu items.

## Pages

- **Home Page:** Browse restaurants, with search and filter options.
- **Login/Signup:** User authentication.
- **Menu Page:** Displays items available for ordering.
- **Cart Page:** View and manage items in the cart.
- **Order Confirmation:** Shows delivery address and order details.
- **Payment and Checkout:** Secure transaction processing.
- **Order History:** View past orders and track current orders.

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/food-ordering-app.git
   ```
   
2. Install dependencies for both client and server:
   ```bash
   cd client
   npm install
   cd ../server
   npm install
   ```

3. Set up environment variables for MongoDB and payment gateway.

4. Run the application:
   ```bash
   npm run dev
   ```
